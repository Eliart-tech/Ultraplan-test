# Exemples d'invocation

## Stratégie seule, sans génération

```text
Utilise illustrations-xiaohei-fr. Ne génère aucune image pour l'instant.
Analyse cet article et propose une shot list d'environ 5 visuels.
Pour chaque image : après quel paragraphe, le sujet, l'idée portée,
le type de structure, ce que fait Xiaohei, les éléments et les annotations proposées.

<coller l'article>
```

## Générer les illustrations d'un article

```text
Utilise illustrations-xiaohei-fr pour produire 4 illustrations pour cet article.
16:9, fond blanc, trait noir manuscrit, quelques annotations françaises rouge/orange/bleu.
Une seule structure par image. Pas d'infographie, pas de cartoon mignon.

<coller l'article>
```

## Stratégie pour un article long

```text
Utilise illustrations-xiaohei-fr pour la stratégie visuelle de ce long article.
Ne répartis pas les images uniformément : vise les ancres cognitives —
jugement central, boucle entrée-sortie, avant/après, pièges, chemin de reprise.
6 à 8 images, shot list uniquement, pas de génération.

<coller l'article>
```

## Une seule image pour une idée

```text
Utilise illustrations-xiaohei-fr pour illustrer cette idée :

« La confiance ne se proclame pas, elle se pose une preuve après l'autre. »

Loufoque mais épuré, Xiaohei porte l'action centrale, 4 annotations maximum, courtes.
```

## Un sujet de workflow

```text
Utilise illustrations-xiaohei-fr pour « transformer une matière brute en trois
contenus : audience, confiance, conversion ».
Pas d'organigramme formel, ne recopie pas la métaphore du poisson.
Réinvente une métaphore peu technologique où Xiaohei fait le geste central.
```

## Retoucher : enlever un titre

```text
Utilise illustrations-xiaohei-fr pour corriger cette image.
Supprime le titre en haut à gauche et son soulignement. Ne change rien d'autre,
n'ajoute aucun texte ni objet.
```

## Retoucher : corriger une faute

```text
Utilise illustrations-xiaohei-fr. L'annotation de cette image est écrite « Resultat ».
Remplace-la par « Ce qui sort », même écriture, même couleur, même position.
Ne modifie rien d'autre.
```

## Retoucher : Xiaohei trop décoratif

```text
Utilise illustrations-xiaohei-fr. La direction est bonne mais Xiaohei fait décoratif.
Régénère en gardant le sens : Xiaohei doit vraiment faire tourner la structure.
Un peu plus étrange, toujours blanc, épuré, peu de texte.
```

## Série de démonstration

```text
Utilise illustrations-xiaohei-fr pour produire 5 illustrations sur des sujets différents :
surcharge d'information, validation produit, effet cumulé du contenu,
entreprise solo, construction de la confiance.
Chaque image générée séparément, pas de planche assemblée.
```
