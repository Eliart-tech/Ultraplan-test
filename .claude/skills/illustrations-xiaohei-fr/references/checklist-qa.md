# Checklist de contrôle

## Points obligatoires

- Format 16:9 horizontal.
- Fond blanc propre.
- Xiaohei est présent.
- Xiaohei porte l'action centrale, il n'est pas décoratif.
- La composition n'est pas une reprise d'un ancien exemple : la métaphore est neuve, née de cet article.
- L'image est étrange, inventive, intrigante.
- Elle est épurée : le sujet n'occupe pas plus de 60 % de la surface.
- Elle ne traite qu'une seule structure.
- Les annotations françaises sont peu nombreuses, courtes, lisibles.
- **Chaque mot est correctement orthographié et correctement accentué.**
- **Aucun caractère chinois ni glyphe CJK dans l'image.**
- L'orange ne sert qu'au chemin principal ou aux flèches.
- Le rouge ne sert qu'à un point d'alerte, un problème, un rappel ou un résultat.
- Le bleu ne sert qu'à un commentaire secondaire, un retour ou un état système.

## Signaux d'échec

Régénérer ou retoucher si :

- un titre apparaît en haut à gauche (« Workflow », « Architecture », « Les pièges », « Feuille de route ») ;
- Xiaohei ressemble à une mascotte, un sticker ou un personnage mignon ;
- l'image évoque une diapositive, un support de cours, un organigramme formel ;
- il y a trop d'éléments, trop de flèches, trop de nœuds ;
- le texte se transforme en paragraphe explicatif ;
- le fond porte une texture, une ombre, un dégradé, du beige ou du grain ;
- on reconnaît une interface applicative ou une esthétique « tech » ;
- **un mot français est mal orthographié ou mal accentué** ;
- **des caractères chinois se sont glissés dans le dessin** — fréquent si le prompt mentionne 小黑 en idéogrammes ; toujours écrire « Xiaohei » en alphabet latin ;
- l'image est rigide, sans métaphore absurde ;
- la composition ressemble trop à un fichier de `assets/examples/`.

## Méthodes d'itération

- **Trop banale** → faire de Xiaohei le sujet de l'action, ajouter une métaphore étrange mais juste.
- **Trop complexe** → supprimer des nœuds, ne garder qu'une action et 3 annotations.
- **Trop mignonne** → insister sur *deadpan*, *blank serious expression*, *not cute*, *not a mascot*.
- **Trop PowerPoint** → retirer titre, cadres, grille régulière et flèches en excès ; revenir à une scène dessinée.
- **Trop proche d'un ancien exemple** → garder le sens, changer l'objet principal et le geste de Xiaohei.
- **Fautes d'orthographe** → une seule faute : retouche locale. Deux ou plus : régénérer avec moins d'annotations. Voir `annotations-francaises.md`.

## Critère de livraison

Une bonne image doit d'abord faire penser « c'est bizarre », puis se laisser comprendre en une seconde.

Si le premier regard évoque une page de tutoriel plutôt qu'un croquis loufoque sur une feuille blanche, c'est raté.

Et si un lecteur francophone tique sur un mot avant de regarder le dessin, c'est raté aussi — même si le dessin est excellent.
