# Xiaohei, le personnage

## Définition

Xiaohei est l'identité visuelle fixe de ces illustrations. Le nom vient du chinois 小黑, « le petit noir ». On le garde tel quel, romanisé : c'est un nom propre, pas une description à traduire. **Il ne s'écrit jamais dans l'image**, ni en chinois ni en français.

Par défaut, Xiaohei apparaît dans chaque image. Ce n'est ni une mascotte, ni un autocollant, ni une décoration mignonne : c'est un ouvrier absurde en train de faire tourner sérieusement un système.

## Silhouette

- Petite créature noire pleine.
- Yeux : deux points blancs.
- Jambes fines, parfois des bras fins.
- Le corps peut être un cylindre, un haricot noir, une boîte noire, un entonnoir, une ombre, l'entrée d'un trou, un bloc sombre à l'intérieur d'une machine.
- Contour légèrement irrégulier, sensation de tracé à la main.
- Expression vide, impassible, calme, appliquée.

## Caractère

- Très consciencieux, mais la tâche est un peu absurde.
- Un opérateur système discret.
- Humour pince-sans-rire, jamais de mièvrerie.
- Un peu maladroit, jamais bête.
- Quelqu'un qui tient réellement un poste dans le croquis.

## Rôles courants

Confier à Xiaohei l'action centrale :

- transporter la matière ;
- tirer des fils pour rassembler des sources ;
- rester coincé dans une rupture ;
- actionner le levier « décision » à l'intérieur d'une machine ;
- se transformer en entonnoir de tri ;
- découper la matière première ;
- tamponner une formulation de reprise ;
- tirer derrière lui le chemin de reprise ;
- brandir un panneau devant une fosse ;
- tendre le bras hors d'un trou sans réussir à rattraper le contenu ;
- à côté : maçonner, construire un pont, ouvrir une porte, trier, consigner.

## Interdits

- Pas de mascotte trop mignonne.
- Pas de personnage de dessin animé pour enfants.
- Pas de vêtements élaborés, pas d'émoticône, pas d'yeux brillants.
- Xiaohei ne reste pas planté dans un coin à regarder.
- Xiaohei ne vole pas la vedette à la structure.
- Pas de rendu trop commercial, trop rond, trop léché.

## Test de validité

Si l'on retire Xiaohei et que la métaphore centrale tient encore parfaitement, c'est qu'il était décoratif. Réécrire le prompt pour qu'il devienne le sujet de l'action.
